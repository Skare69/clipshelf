# Security policy

## Supported versions

Security fixes go to the latest release only.

| Version | Supported |
|---|---|
| Latest release (v0.11.x) | Yes |
| Older releases | No |

## How to report a vulnerability

Report through private vulnerability reporting:
[Security → Report a vulnerability](https://github.com/Skare69/clipshelf/security/advisories/new).

Do not open a public issue or a pull request for a security problem.
Keep the details private until the fix release.

Please include:

- The release tag or container tag that you run.
- Your deployment: compose, another container runtime, or local.
- The impact that you see, and the steps that show it.

## What to expect

GitHub notifies the maintainer at once. You get a reply, and we coordinate the
fix and the disclosure with you. Your name goes into the release notes, unless
you ask us to omit it. There is no bug bounty.
