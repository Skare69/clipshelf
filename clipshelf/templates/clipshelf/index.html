Import a TikTok export or a library.json

Accepts a TikTok browser export (tiktok.json) or a legacy library.json. The server rejects an export above its import ceiling as a whole and never cuts it. A legacy library keeps its media only if its old cache/ directory was first copied to import-cache/ in the server data directory. Otherwise the entries come in without media, and the manifest lists what is missing.
